# Basiumlabs

Video editing portfolio — "The Edit Bay" direction. Next.js (App Router) + TypeScript + Tailwind CSS v4, with GSAP for the hero/chapter choreography, scroll-linked hero movement and the cursor tag.

**Deploying:** see [DEPLOYMENT.md](DEPLOYMENT.md) (GitHub → Vercel, media on Cloudflare R2).

## Run locally

```bash
npm install
npm run media:encode            # builds web media into public/media (needs ffmpeg/ffprobe); skips existing files
npm run build && npm start      # or: npm run dev
npm run check:browser           # end-to-end checks against http://localhost:3100 (needs Edge or Chrome)
npm run lint && npm run typecheck
```

The encoder reads the original masters from the parent folder (`../Long Form`, `../Product Launch`, `../Short Form`; override with `MEDIA_SOURCE_ROOT`) and never modifies them. `--force [slug…]` rebuilds.

## Content and media

- `src/content/catalog.json` — editorial data: title, format, category (assigned by content, not folder), source file, poster/preview points, rotation fix.
- `src/content/media-manifest.json` — generated by the encoder from the encoded files: dimensions, duration, fps, audio, file sizes. The site reads every measurement from here.
- `src/content/projects.ts` — merges the two; a project appears only once its media exists. Also defines chapter order and the showreel order.

Per project, `public/media/<slug>/` holds `sd.mp4` (long edge ≤ 1280, default/mobile), `hd.mp4` (≤ 1920, desktop only, when the source is larger), `preview.mp4` (6 s muted loop) and `poster.jpg`. `public/media/` is git-ignored; production serves it from `NEXT_PUBLIC_MEDIA_BASE_URL`.

## Brand assets

- `public/brand/basiumlabs-mark.svg` — the orbital mark redrawn as vector from the MVP end card (12 concentric, progressively rotated rings and the blue `#4262E6` dot), white on transparent.
- `src/app/icon.svg` — tab icon: the same mark optically sized for 16–32 px (fewer, heavier rings); ring colour follows the browser's light/dark scheme.
- `src/app/favicon.ico` (16/32/48, outlined white rings for any tab colour) and `src/app/apple-icon.png` (180 px, on `#0A0A0B`) are rasterised from those SVGs.
