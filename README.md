# Abhishek Pandey — Portfolio

Personal video editing portfolio of Abhishek Pandey. Next.js (App Router) + TypeScript + Tailwind CSS v4. The look follows the frosted-glass, visionOS-style reference in `../reference/`: a floating glass window with a hero carousel, side panels and a card row.

**Deploying:** see [DEPLOYMENT.md](DEPLOYMENT.md) (GitHub → Vercel, media on Cloudflare R2).

## Run locally

```bash
npm install
npm run media:encode            # builds web media into public/media (needs ffmpeg/ffprobe); skips existing files
npm run build && npm start      # or: npm run dev
npm run check:browser           # end-to-end checks against http://localhost:3100 (needs Edge or Chrome)
npm run lint && npm run typecheck
```

The encoder reads the original masters from the parent folder (`../Long Form`, `../Product Launch`, `../Short Form`; override with `MEDIA_SOURCE_ROOT`) and never modifies them. `--force [slug…]` rebuilds. `check:browser -- --loose-media` skips the byte-size checks when testing with stand-in clips.

## Editing content

- `src/content/profile.ts` — name, positioning, intro, about text, facts and **contact links** (empty links are hidden; the contact panel shows no links until you add them).
- `src/content/catalog.json` — one entry per film: title, format, category, source file, poster/preview points, rotation fix.
- `src/content/media-manifest.json` — generated by the encoder: dimensions, duration, fps, audio, file sizes.
- `src/content/projects.ts` — merges the two, defines the filter categories, the hero carousel picks (`FEATURED`) and the showreel order. A project appears only once its media exists in the manifest.

Per project, `public/media/<slug>/` holds `sd.mp4` (long edge ≤ 1280, default/mobile), `hd.mp4` (≤ 1920, desktop only, when the source is larger), `preview.mp4` (6 s muted loop) and `poster.jpg`. `public/media/` is git-ignored; production serves it from `NEXT_PUBLIC_MEDIA_BASE_URL`.

## Page structure

- `src/components/workspace.tsx` — the glass window: name chip, filter tabs, Reels and All-edits panels, Selected-work grid.
- `src/components/hero.tsx` — carousel: intro slide (name + showreel) then the featured films, each looping muted behind the text.
- `src/components/player.tsx` — full-screen player dialog with queue, keyboard N/P, HD on desktop.
- `src/components/profile-sections.tsx` — About and Contact panels. `side-rail.tsx` — the floating icon rail (≥ 1280 px).
- `src/app/opengraph-image.tsx` — the link-preview image (name and positioning, no logo).
